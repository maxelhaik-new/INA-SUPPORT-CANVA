### Slide 09 · Droit d'auteur
- **Badge / Sur-titre** : `Droit d'auteur`
- **Chapô d'accroche** : Un contenu généré entièrement par une IA, sans apport humain substantiel, *n'est pas protégé par le droit d'auteur.*
- **Sur-titre de section** : Avant de publier, vérifiez
- **Cartes de contrôle** :
  - **01 · Les marques** : L'IA glisse parfois de vrais logos dans les images. Retirez-les.
  - **02 · Les visages** : Un visage qui ressemble à une personne réelle demande une cession de droits.
  - **03 · Les chiffres** : Un chiffre donné par une IA se vérifie dans sa source d'origine.

### Slide 11 · Le constat
- **Badge / Sur-titre** : `Le constat`
- **Titre principal** : Les prompts très longs *fonctionnent mal*
- **Chapô** : Trop de consignes rigidifient le modèle. *Ses réponses deviennent convenues ou s'éloignent du sujet.*
- **Comparatif Avant / Aujourd'hui** :
  - **Avant** : Trois pages de consignes détaillées
  - **Aujourd'hui** : Un prompt court avec un contexte métier précis

### Slide 12 · Structure d'un prompt
- **Badge / Sur-titre** : `Structure d'un prompt`
- **Titre principal** : Les 4 éléments *d'un bon prompt*
- **Cartes des piliers** :
  - **1 · Le rôle et le contexte** : Qui parle, à quel public, dans quel secteur.
  - **2 · La tâche** : Une seule demande, formulée avec un verbe d'action.
  - **3 · La matière source** : Le brief, un mail ou des données brutes, collés dans la conversation.
  - **4 · Le format attendu** : Le type de livrable, le ton et la longueur.

### Slide 19 · Livrable 3 · PowerPoint
- **Badge / Sur-titre** : `Livrable 3 · PowerPoint`
- **Titre principal** : De Claude à Gamma *en 4 étapes*
- **Les 4 étapes** :
  - **1** : Claude rédige le plan balisé.
  - **2** : Copiez le texte.
  - **3** : Dans Gamma, choisissez Coller du texte, format 16:9.
  - **4** : Appliquez la charte, puis exportez en .pptx.
- **Prompts modèles** :
  - `À partir de la note de cadrage, prépare le plan d'un pitch de 8 slides pour partenaires et mécènes.`
  - `Markdown pur : un titre # par slide, un sous-titre d'une ligne, 3 puces de 15 mots maximum. Aucun commentaire.`
